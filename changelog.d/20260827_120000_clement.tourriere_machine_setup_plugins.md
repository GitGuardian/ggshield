### Added

- `ggshield machine setup` now also installs the plugins the account is entitled
  to — including `machine_scan`, which provides `ggshield machine scan` — instead
  of leaving that to a manual `ggshield plugin install`. Entitlement comes from
  the platform catalog, so an account with no plugins available (or a workspace
  with the plugin system off) simply skips the step rather than failing the
  setup. Signature verification stays strict, an already-installed plugin is not
  upgraded (that stays `ggshield plugin update`) but is enabled if it was off,
  and a root run installs machine-wide like the git hooks (`--system` without
  root passes when the plugins are already set up machine-wide, and reports an
  error instead of installing or enabling them per-user). A plugin with no build
  for the machine's platform is skipped. Skip the step with `--no-plugins`.
