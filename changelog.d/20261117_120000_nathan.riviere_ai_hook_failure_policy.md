### Added

- New `secret.ai_hook_failure_policy` setting (`allow` or `block`, default `allow`), also available as the `GITGUARDIAN_AI_HOOK_FAILURE_POLICY` environment variable, decides what `ggshield secret scan ai-hook` does with an action it cannot scan: an unrecognized agent, a missing or unreadable token, an API error or a timeout. With `allow`, the action goes through: a known agent shows that it was not scanned, while an unrecognized agent only gets a warning on stderr, which most agents do not display. With `block`, it is denied.

### Fixed

- `ggshield secret scan ai-hook` no longer exits 1 for an agent it does not recognize, which made the GitHub Copilot desktop app deny every tool call while other agents ran them unscanned without notice. It now follows `secret.ai_hook_failure_policy`: exit 0 to allow, exit 2 to block.
