### Added

- ggshield can now read, write and inject secrets from your secret manager:
  `ggshield secret get`, `set`, `unset`, `list`, `import` and `encrypt`, plus
  `ggshield run`, `ggshield activate` and `ggshield trust`. HashiCorp Vault and
  dotenv files encrypted with a device-local key are supported.
  `ggshield secret import --provider file --remove-source .env` turns an
  existing dotenv file into managed secrets, and `ggshield run -- <command>`
  passes them to a command as environment variables without ever writing them
  to disk.
