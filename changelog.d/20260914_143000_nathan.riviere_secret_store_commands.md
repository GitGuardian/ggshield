### Added

- ggshield can now read, write and inject secrets from your secret manager:
  `ggshield secret get`, `set`, `unset`, `list`, `import` and `encrypt`, plus
  `ggshield run`, `ggshield activate` and `ggshield trust`. HashiCorp Vault and
  dotenv files encrypted with a device-local key are supported.
  `ggshield secret import` copies an existing dotenv file into managed secrets,
  and `ggshield run -- <command>` passes them to a command as environment
  variables without ever writing them to disk.
- Values encrypted by the file provider can only be read on the device that
  encrypted them: the key lives in the OS keychain, with no export or backup,
  so they are lost if the keychain is reset. Keep another copy of anything you
  cannot recreate before deleting the source (`import --remove-source`).
