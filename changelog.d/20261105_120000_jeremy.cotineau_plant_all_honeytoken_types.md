### Added

- `ggshield honeytoken plant --type all` plants every honeytoken type the workspace offers, each with its default placement. Types the workspace does not offer are skipped. It fails when a type returns any other error, or when no type can be planted. It cannot be combined with `--method`, `--filename` or `--profile-name`.

### Changed

- `ggshield machine setup` now plants every honeytoken type the workspace offers (AWS and kubeconfig), not only AWS, so it can also write a kubeconfig context under `~/.kube/`. It exits with an error when a type the workspace offers cannot be planted.
