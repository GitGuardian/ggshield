### Added

- `ggshield machine setup` can now provision a **machine-wide service-account token** for fleet/MDM deployment. Provide the token via the `GGSHIELD_SERVICE_ACCOUNT_TOKEN` environment variable (or piped on stdin) together with `--instance`, and setup validates it and stores it in a machine-wide config file that **every account on the machine** falls back to — so the git hooks, AI hooks and honeytoken work without each user running `ggshield auth login`. A user's own `ggshield auth login` and `GITGUARDIAN_API_KEY` still take precedence; the machine-wide token is the fallback. Writing it requires root (the same context as `--system` git hooks).
