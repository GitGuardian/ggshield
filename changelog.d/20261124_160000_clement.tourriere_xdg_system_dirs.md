### Fixed

- ggshield looks for machine-wide plugins and `enterprise_config.yaml` in the fixed system locations and every eligible entry in `XDG_DATA_DIRS` and `XDG_CONFIG_DIRS`, respectively.
- By default, root installs write to `/usr/local/share/ggshield` and `/etc/xdg/ggshield` on Linux and `/Library/Application Support/ggshield` on macOS. If a plugin installed from a desktop session is missing in other sessions, reinstall it with `sudo ggshield plugin install`.
- `ggshield plugin list -v` shows every `XDG_DATA_DIRS` / `XDG_CONFIG_DIRS` entry it searched, and the entries it skipped (not found, unsafe or invalid).
