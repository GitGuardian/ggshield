### Fixed

- `ggshield install` no longer loses the pushed refs when the repository has its own `pre-push` hook. The global hook now replays git's stdin to that hook and to `ggshield`, so a repository using pre-commit, Husky, lefthook or any other hook manager is still scanned on push instead of reporting "Deletion event or nothing to scan" and letting the push through unscanned.
- Hooks written by an older `ggshield` are repaired whatever version stamp they carry, and the repair leaves a single stamp behind. A `pre-push` hook installed by an earlier version is recognised instead of being reported as hand-edited by `machine setup`.
