### Security

- `ggshield machine` commands do not load the `.env` file of the current directory or repository. These commands also do not use the `instance` and `insecure` values of the repository's `.gitguardian.yaml` file. A warning shows the values that they did not use. Before this change, a cloned repository could use these files to send the machine data and your API key to a different instance. Other commands use these files as before. Machine commands load the file that `GITGUARDIAN_DOTENV_PATH` sets. To select the instance of a machine command, use `--instance`, `GITGUARDIAN_INSTANCE`, `~/.gitguardian.yaml` or `--config-path`.
- On macOS, `ggshield machine setup` runs the token check of the AI hook outside the current repository. Before this change, the `.env` and `.gitguardian.yaml` files of the repository could select the instance that receives the token.
