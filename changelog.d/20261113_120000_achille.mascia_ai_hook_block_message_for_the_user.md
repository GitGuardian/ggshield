### Changed

- When the AI hook blocks a secret, the message the agent reads no longer suggests a way to ignore it, on any agent. It tells the agent to relay the notice without suggesting to ignore the secret or to disable the hook.
- The false-positive hint now goes to the user only. On Claude Code it is shown as a system message. On other agents it comes in a desktop notification, which the hook now raises for every block that has a hint to give, not only when a secret reached the agent.
- The AI hook no longer offers a false-positive hint for a secret checked as valid. When some of the reported secrets are valid, the hint covers the others only and does not suggest `--last-found`, which would ignore the valid ones too.
