### Changed

- When the AI hook blocks a secret, the message the agent reads no longer suggests a way to ignore it, on any agent. It tells the agent to relay the notice without suggesting to ignore the secret or to disable the hook.
- The false-positive hint now goes to the user only, in the agent's own interface where it has a field the model does not read: on every Claude Code block, on Codex prompt and tool blocks, on Cursor prompt and pre-tool blocks, on VS Code tool blocks, and on Mistral Vibe post-tool blocks. Elsewhere (Copilot CLI, Junie, Kiro and the other events) it comes in a desktop notification, which the hook now raises for every block that has a hint to give, not only when a secret reached the agent.
- The AI hook no longer offers a false-positive hint for a secret checked as valid. When some of the reported secrets are valid, the hint covers the others only and does not suggest `--last-found`, which would ignore the valid ones too.
